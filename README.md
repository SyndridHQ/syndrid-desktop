# Syndrid Desktop

Syndrid Desktop is the native visual engineering workbench for the Syndrid runtime.

The desktop application is intentionally a client of `SyndridHQ/syndridcli`: SyndridCLI owns model execution, routing, orchestration, tools, MCP, sessions, permissions, memory, and runtime lifecycle. The desktop observes, controls, and explains those capabilities through the Syndrid app-server protocol.

> Breadth at rest, precision in use.
